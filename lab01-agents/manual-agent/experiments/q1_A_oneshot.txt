Оператор **`menu`** в Ren'Py — це один із найважливіших інструментів. Він використовується для створення **інтерактивних виборів** (розгалужень сюжету), де гравець може обрати одну з кількох опцій, що впливає на подальший хід гри.

Ось детальний розбір того, як працює `menu`, від простого до просунутого використання.

---

### 1. Базовий синтаксис

Найпростіше меню складається з ключового слова `menu:`, за яким ідуть варіанти відповідей з відступами (4 пробіли).

```renpy
label start:
    "Я стою на роздоріжжі. Куди мені піти?"

    menu:
        "Піти ліворуч":
            "Я пішов ліворуч і знайшов скриню з сокровищами!"
        
        "Піти праворуч":
            "Я пішов праворуч і зустрів дикого ведмедя."

    "Пригода триває..."
```

> **Зверніть увагу:** Відступи в Ren'Py мають вирішальне значення (як у Python). Все, що знаходиться всередині варіанту вибору, має бути зміщено праворуч.

---

### 2. Меню із запитанням (Prompt)

Ви можете вставити текст запитання безпосередньо всередину блоку `menu`. У такому разі цей текст буде відображатися як репліка персонажа або системний текст над кнопками вибору.

```renpy
label start:
    menu:
        a "Що ти хочеш випити?" # Репліка персонажа 'a'

        "Каву":
            a "Ось твоя кава."
        "Чай":
            a "Заварюю зелений чай."
```

---

### 3. Переходи між мітками (`jump`)

Зазвичай вибори не просто виводять рядок тексту, а переводять гравця в іншу частину сюжету (в інший `label`). Для цього використовується оператор `jump`.

```renpy
label start:
    menu:
        "Піти до школи":
            jump school_route
        "Залишитися вдома":
            jump home_route

label school_route:
    "Ви прийшли до школи. Уроки вже почалися."
    return

label home_route:
    "Ви вирішили поспати ще декілька годин."
    return
```

---

### 4. Зміна змінних під час вибору

Ви можете змінювати значення змінних (наприклад, бали прихильності персонажів або гроші) безпосередньо всередині блоку вибору, використовуючи знак `$`.

```renpy
default alice_love = 0

label date:
    menu:
        "Похвалити її сукню":
            $ alice_love += 1
            a "Ой, дякую! Мені дуже приємно."

        "Сказати, що вона запізнилася":
            $ alice_love -= 1
            a "Вибач, були затори..."
```

---

### 5. Умовні вибори (Умови `if`)

Ви можете показувати певні варіанти відповідей **тільки тоді**, коли виконується якась умова (наприклад, у гравця є потрібний предмет або достатньо балів).

```renpy
default has_key = False
default money = 50

label door:
    menu:
        "Просто відкрити двері":
            "Двері заперті."

        # Цей варіант з'явиться ТІЛЬКИ якщо has_key == True
        "Вставити ключ у замок" if has_key:
            "Ви відкрили двері ключем!"
            jump inside_room

        # Цей варіант з'явиться, якщо грошей 100 або більше
        "Підкупити охоронця (100 монет)" if money >= 100:
            $ money -= 100
            "Охоронець пропустив вас."
            jump inside_room
```

> **Порада:** За замовчуванням, якщо умова `if` не виконується, кнопка взагалі не показується. Якщо ви хочете, щоб кнопка показувалася, але була неактивною (сірою), це можна налаштувати через `config.menu_include_disabled = True`.

---

### 6. Одноразові вибори (Запам'ятовування зробленого вибору)

Якщо ви хочете зробити меню діалогу, де гравець може поставити кілька запитань, і ви хочете, щоб вже поставлені запитання зникали:

```renpy
label questions:
    menu:
        "Хто ти?" set questions_set:
            a "Я місцевий чарівник."
            jump questions

        "Що це за місце?" set questions_set:
            a "Це зачатй ліс."
            jump questions

        "Тобі потрібна допомога?":
            a "Так, допоможи мені знайти зілля!"
            jump next_quest
```
Конструкція `set questions_set` автоматично додає обраний пункт до множини `questions_set` і ховає його при повторному виклику меню.

---

### Резюме
* **`menu:`** створює список кнопок для вибору.
* Кожен варіант оформлюється як `"Текст вибору":`.
* Всередині вибору можна виконувати будь-який код Ren'Py або Python (діалоги, `jump`, `$ variable = value`).
* За допомогою `if` можна ховати вибори на основі стану гри.
