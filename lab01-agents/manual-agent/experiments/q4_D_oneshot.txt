Оператор **`screen`** в Ren'Py — это фундаментальный элемент для создания пользовательского интерфейса (UI). С его помощью верстаются меню, инвентари, диалоговые окна, кастомные всплывающие подсказки, мини-игры и любые другие графические элементы, с которыми может взаимодействовать игрок.

Экранный язык Ren'Py (Screen Language 2) декларативен, похож на смесь HTML/CSS и Python.

---

### 1. Базовый синтаксис

 Экран объявляется с помощью ключевого слова `screen`, за которым следует имя экрана и (опционально) параметры:

```renpy
screen my_first_screen():
    # Элементы интерфейса пишутся с отступом
    frame:
        xalign 0.5
        yalign 0.5
        text "Привет, это мой первый экран!"
```

---

### 2. Как вызывать и закрывать экраны

Экран можно отобразить из обычного сценария Ren'Py двумя способами:

1. **`show screen name`** — показывает экран "на фоне". Игра продолжается, игрок может читать диалоги, а экран висит на поверх всего.
2. **`call screen name`** — вызывает экран в **блокирующем** режиме. История останавливается и ждет, пока игрок что-то не сделает на экране (например, не нажмет кнопку, возвращающую значение через `Return()`).
3. **`hide screen name`** — скрывает экран.

```renpy
label start:
    show screen my_first_screen # Экран появился
    "Сценарий продолжается параллельно..."
    hide screen my_first_screen # Экран исчез

    call screen my_first_screen # Игра ждет действий на экране
    "Этот текст появится только ПОСЛЕ закрытия экрана."
```

---

### 3. Главные свойства самого экрана (Header Keywords)

Перед телом экрана можно задать его глобальные поведение и правила:

* **`modal True`** — делает экран модальным. Игрок не сможет кликать по элементам *под* этим экраном (блокирует нижние слои).
* **`tag name`** — присваивает тег. Если показать другой экран с таким же тегом, текущий автоматически закроется (используется для переключения между вкладками меню).
* **`zorder int`** — порядок отрисовки (слой). Экран с `zorder 2` будет перекрывать экран с `zorder 1`.
* **`style_prefix "str"`** — автоматически применяет стиль ко всем элементам внутри (например, `style_prefix "my_menu"`).

```renpy
screen pause_menu():
    modal True
    tag menu
    zorder 100
    # ...
```

### 4. Основные элементы (Displayables) внутри экрана

Внутри `screen` используются встроенные контейнеры и виджеты:

#### Контейнеры (для компоновки):
* **`vbox`** — выстраивает дочерние элементы **вертикально**.
* **`hbox`** — выстраивает дочерние элементы **горизонтально**.
* **`frame`** — рамка/подложка (плашка), в которую помещаются элементы.
* **`fixed`** — контейнер, позволяющий накладывать элементы друг на друга с абсолютным позиционированием.
* **`grid x y`** — сетка из `x` колонок и `y` строк (должна быть заполнена полностью!).

#### Элементы отображения и взаимодействия:
* **`text "..."`** — вывод текста.
* **`add "image.png"`** — вывод изображения или другого графического объекта.
* **`textbutton "Текст"`** — текстовая кнопка.
* **`imagebutton`** — кнопка-картинка (требует указания состояний `idle`, `hover` и т.д.).
* **`bar` / `vbar`** — шкала/прогресс-бар (горизонтальный / вертикальный).
* **`key "key_name"`** — отслеживание нажатия клавиш на клавиатуре (например, `key "K_ESCAPE" action Return()`).

---

### 5. Действия (Actions)

Интерактивные элементы (кнопки, клавиши) используют **Actions** для выполнения команд при нажатии.

Популярные действия:
* `action Show("screen_name")` — открыть другой экран.
* `action Hide("screen_name")` — скрыть экран.
* `action ToggleVariable("var_name")` — переключить булевую переменную (True/False).
* `action SetVariable("var_name", value)` — присвоить значение переменной.
* `action Jump("label_name")` — перейти к метке в коде.
* `action Return(result)` — закрыть экран (если вызван через `call`) и вернуть значение.

---

### 6. Передача параметров и динамика Python

Экран может принимать аргументы и использовать внутри себя логику Python (`if`, `for`):

```renpy
# Экран принимающий параметры
screen character_card(name, hp, max_hp):
    frame:
        xpadding 20
        ypadding 20
        vbox:
            spacing 10
            text "Персонаж: [name]"
            text "Здоровье: [hp]/[max_hp]"

            # Условие
            if hp < 20:
                text "Внимание: Мало HP!" color "#f00"

            textbutton "Закрыть" action Hide("character_card")

# Вызов экрана с передачей данных:
label show_stat:
    show screen character_card(name="Алиса", hp=15, max_hp=100)
```

Использование циклов для динамических списков:
```renpy
screen inventory_screen(items):
    vbox:
        for item in items:
            textbutton item action Return(item)
```

### Пример сложного экрана

Вот пример всплывающего окна подтверждения (Confirm Dialog):

```renpy
screen my_confirm(message, yes_action, no_action):
    modal True # Не даем кликать под экран
    zorder 200

    # Полупрозрачный задний фон на весь экран
    add "#00000088"

    # Окно по центру
    frame:
        xalign 0.5
        yalign 0.5
        xsize 400
        ysize 200

        vbox:
            xalign 0.5
            yalign 0.5
            spacing 30

            text message:
                xalign 0.5
                textalign 0.5

            hbox:
                xalign 0.5
                spacing 50
                textbutton "Да" action yes_action
                textbutton "Нет" action no_action
```

**Как это вызвать:**
```renpy
label quit_job:
    call screen my_confirm("Вы уверены, что хотите уволиться?", Jump("do_quit"), Hide("my_confirm"))
```
